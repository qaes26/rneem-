# 🎯 رنيم — Rneem Pediatric Speech Therapy App

تطبيق محرك رؤية حاسوبية وتخاطب رقمي للأطفال العرب (Pediatric Speech Therapy & Computer Vision) باستخدام الذكاء الاصطناعي **Gemini Vision API**.

## 🌟 المميزات

- 🎥 **الكشف والالتقاط التلقائي الفوري (Real-Time Auto-Capture)**: يتعرف على العناصر بمجرد توجيه الكاميرا.
- 🔤 **تشكيل كامل مائة بالمائة (Mandatory Tashkeel)**: إضافة التشكيل الكامل على جميع الحروف لضمان نطق دقيق من محركات الصوت (TTS).
- 🧩 **تقطيع صوتي (Phonics Breakdown)**: تقسيم الكلمة إلى مقاطع صوتية متباعدة بشرطات تسهل محاكاة النطق للطفل.
- 🎉 **تشجيع إيجابي (Positive Reinforcement)**: عبارات تشجيع حماسية ومبهجة للأطفال.
- 🔊 **نطق صوتي متسلسل (Sequential TTS)**: نطق أسماء الإشارة + الكلمة + التقطيع + التشجيع مع وقفات زمنية طبيعية.
- 🔑 **خصوصية تامة**: مفتاح API يُحفظ محلياً على جهاز المستخدم فقط (`localStorage`).

## 🚀 كيفية التشغيل المحلي

1. افتح المشروع في أي خادم محلي (Local Server):
   ```bash
   npx serve -l 3000
   ```
2. افتح المتصفح على: `http://localhost:3000`
3. أدخل مفتاح **Gemini API** المجاني من [Google AI Studio](https://aistudio.google.com/apikey).
4. اضغط **ابدأ الآن** ووجّه الكاميرا إلى أي عنصر!
